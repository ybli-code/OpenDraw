# STYLE-004｜摄影 × 线描旅行海报

基于公开 Photo × Line Art Travel Poster 创作规范重新整理的 OpenDraw 适配版。与 STYLE-002 的区别：固定2:3画幅、单个7–10%高度的线描人物、黑色钢笔线条主导而非混合剪纸拼贴。

## 适用
上传旅行、城市、海岸、建筑、道路、桥梁等照片，要求“使用 STYLE-004”。每张照片独立制作一张海报，不拼接多张来源图片。最好选择照片下缘附近存在可连续延伸的道路、水面、岸线、台阶或建筑边缘的画面。

## 生成提示词（OpenDraw 独立整理版）
以用户上传的照片制作一张 2:3 竖版摄影与线描融合的高级旅行编辑海报。严格将画布水平分为各占50%的上下两部分。

**上半：原照片。** 忠实保留照片中的地标、建筑、人物、自然景观、空间结构、光照、颜色与真实摄影质感。不要把照片重绘成插画，不改变主体和原有关系。若画幅不匹配，优先自然扩展外围环境，避免拉伸或截断重要主体。

**下半：纸上世界。** 使用干净、微暖的象牙色纸面，带极轻微的细纤维感，留出大面积空白。以纤细、略带手绘不规则感的黑色钢笔线条为主要视觉语言，不绘制密集复杂的完整场景。

**连续转化。** 从上半照片中寻找一条最有辨识度、能够到达画面中央分割线的真实结构：路、台阶、海岸、水纹、桥、绳索、树枝、建筑边缘或光线等。让它从准确接触点穿过分割线，连续地由摄影细节转为下半部的黑色手绘线条。线条不应凭空另起，也不能让上下成为两个不相关的场景。每张照片依据原有结构设计独一无二的延续方式。

**微型人物。** 在下半部安排一个小小的黑墨线描人物，高度约占整幅海报的7–10%。人物应与延伸结构发生实际互动，例如行走、攀爬、拉动、推送、倚靠、观望或休息。动作应自然，人物服装简略、表情极少、线条轻松；不要成为主体，也不要悬空。

**文案。** 在留白处加入一条与具体场景相关的2–5词英文短句，轻盈、温和、有旅行感。使用小尺度、克制的编辑式排版，绝不做醒目商业大标题。

**整体气质。** 真实摄影、细黑钢笔线条、诗意连续的空间想象、暖象牙纸面、独立旅行杂志排版。画面明亮、安静、精致而有巧思，留白比装饰更重要。

**禁止。** 上下画面脱节、孤立漂浮物、人物过大或过多、卡通动漫、粗黑描边、密集速写、整个下半部填满插画、信息图、网格、邮票边框、复杂拼贴、黄色旧纸、Logo、水印和过量文字。

## 与 STYLE-002 的区分
- STYLE-002：3:4，更强调“第二世界”可触摸的概念转化，允许0–3人、照片碎片与剪纸。
- STYLE-004：2:3，强调一条连续黑色钢笔线、一个小人物和2–5词的英文短句。

## 质量检查
- [ ] 2:3竖版，上下各50%
- [ ] 上半照片主体、光影、颜色与空间关系忠实
- [ ] 至少一条来自原照片的结构无断裂地穿越分割线
- [ ] 下半是象牙纸、大面积留白、纤细黑色线稿
- [ ] 仅一个7–10%画面高度的互动线描人物
- [ ] 英文短句2–5词，排版克制
- [ ] 无漂浮人物、孤立图标或完整场景复绘
