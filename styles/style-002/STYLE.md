# STYLE-002｜第二世界 · 连续拼贴海报

## 调用
上传一张照片，说“使用 STYLE-002 制作第二世界海报”。每张上传照片单独成稿，不合并多张照片。

## 完整提示词
每次上传请制作一张独立的“第二世界”海报。切勿合并照片。

**画幅：** 竖版 3:4 画布，水平分割成上下各 50%，上下各占一半。上半部分保留照片原貌；下半部分构成“第二世界”的延伸。两者必须浑然一体。

**上半部分：** 忠实还原照片。保留主体、姿势、空间关系、色彩氛围和自然元素，不得重新设计、重绘、替换或重新布置。仅允许必要的比例裁剪。

**连贯性：** 上下衔接至关重要。找到一个自然延伸至画面中心分割线的元素，例如道路、海岸线、水面、倒影、树枝、光线、建筑或人体动作。该元素必须跨越分割线并延伸至下半部分。“第二世界”必须从照片本身开始，因此同一场景能够穿过分割线并改变物理规则。

**过渡边缘：** 中心部分可以使用不规则的撕纸边缘，但撕痕必须与源结构相符，而非作为装饰。允许源元素接触、跟随、突破或延伸到边缘之外。切勿在每幅图像上都使用相同的撕痕形状。

**下半部分：** 使用纤维细腻、留白丰富的象牙色纸张。从与分割线相交的确切位置向下延伸所选结构，然后用克制的照片碎片、剪纸造型和极简的黑色手绘线条重新诠释它。下半部分必须保持可见的连接。除非明确源自照片，否则切勿将其隔离为单独的入口、窗口、舞台、平台或漂浮的场景。

**第二世界逻辑：** 思考：如果这个结构变得可触摸、可用、可进入或可改变，它自然会变成什么？创建一个与图像相关的交互方式。例如，水在被拉动时可能保持附着状态，道路可能以绘制路径的形式延续，或者光线可能变成某种非机械重复的动作。创意须从原照片自然生长，避免套用固定桥段。

**人物：** 仅在必要时添加 0–3 个细小的黑色线条人物。它们必须与延续的结构进行物理互动。如果源图像已经包含强烈的人类动作，则无需添加人物。切勿将人物用作装饰。

**标题：** 根据动作添加一条简短的手写英文标题。保持自然、轻松，并略带机智。不要励志名言，避免使用固定的“相同……不同……”句式。

**风格：** 上方为真实照片，下方为暖色调纸张，极简的黑色线条涂鸦，微妙的手工拼贴纹理，独立杂志风格，明亮、轻盈、克制。最终效果应给人一种感觉，仿佛第二个世界早已隐藏在照片之中，并向下延伸。

## 创作步骤
1. 分析照片最有识别度的主体和可穿越中心线的结构。
2. 选择与原图语义相关、可自然发生的交互动作。
3. 保留上半照片，规划准确的上下 50% 分界。
4. 从同一结构的准确接触点向下延伸纸本拼贴形态。
5. 根据需要加入 0–3 个互动线条人物和简短手写英文标题。
6. 检查上下世界是否连续，而非两个独立画面。

## 负面约束
- 不要将上半照片重绘、改变身份、姿势、建筑或自然元素。
- 不要上下比例失衡、拉伸原图、拼接多张源照片。
- 不要在下方凭空创建独立窗口、舞台、孤岛、平台或装饰性场景。
- 不要每张图复用相同撕纸边界、固定人物或固定文案。
- 不要密集涂鸦、过多人物、繁复颜色、机械式视觉噱头。
- 不要励志标语或商业海报式大标题。

## 验收清单
- [ ] 竖版 3:4，上下各占严格 50%
- [ ] 上半原图真实且结构忠实
- [ ] 至少一个原图结构跨越分割线并在下方可见地延续
- [ ] 下方是象牙纸、克制照片碎片、剪纸与细黑线条
- [ ] 互动机制与照片有因果关联，不是孤立插画
- [ ] 线条人物数量 0–3，若存在则与结构互动
- [ ] 手写英文标题简短、轻松、不说教
- [ ] 整体留白充足，具独立艺术杂志气质

## 示例构思
冬日天鹅湖照片：让真实水面穿过中心线，化作下半纸面上的蓝色拼贴水流；一个小线描人物轻触水流，产生与真实水纹相连的涟漪。此例只说明机制，不应在其他照片上机械复用。
